# Changelog

## 0.1.0 (18 November 2026)

First version.

- Hold Cmd (Ctrl on Windows and Linux) and click a code block in the Claude Code terminal to copy it as it was written.
- A **Copy block** button in the status bar copies the newest code block. If the newest reply has several blocks, a list opens.
- Two commands in the command palette: "Copy newest code block" and "Copy a code block from a list".
